# cellive-quiz-serum

Quiz da Cellive Skin que, ao final, leva a uma página de venda.

- Site estático em `public/` (HTML, CSS e JavaScript puro), publicado na Vercel.
- Para rodar localmente: `npm install` e `npm start` → http://localhost:3000
- Documentação do projeto: `CLAUDE.md`, `specs/site.md`, `specs/design.md` e `memoria.md`.
